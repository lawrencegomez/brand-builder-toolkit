# Site Copy

Order matters: **structure, then words, then visuals.** Copy written before the
structure gets cut; visuals designed before the copy get lorem ipsum forever.

If installed, lean on Corey Haines' skills: `site-architecture` for the sitemap,
`copywriting` for new copy, `copy-editing` for improving existing copy,
`marketing-psychology` for persuasion. Then always `humanizer` last.

## Step 1: Sitemap and page outlines

Read `brand/BRAND.md` (customer, why, the website's primary action) and
`brand/PLATFORM.md`. Propose the smallest sitemap that does the job. Most small
businesses need 3 to 5 pages: Home, About, Services or Products, Contact (plus Pricing,
FAQ, or Work when they earn their place). One-page sites are fine for early stages.

For each page, outline sections in order, each with a one-line job. Example home page:

1. Hero: who it is for + the outcome + primary action
2. Proof: logos, numbers, or a short testimonial (only real ones)
3. The problem, in the customer's words
4. How it works: 3 steps
5. Offer details
6. Objections and FAQ
7. Final call to action

Confirm the sitemap and outlines with the person before writing.

## Step 2: Pick a framework per section, and say which

Teach while you write: name the framework you are using and why, in one line.

| Framework | Shape | Best for |
|---|---|---|
| **PAS** | Problem, Agitate, Solution | Services that fix a pain |
| **AIDA** | Attention, Interest, Desire, Action | Home page flow overall |
| **StoryBrand** | Customer is the hero, brand is the guide with a plan | About pages, mission-led brands |
| **Before-After-Bridge** | Life before, life after, how we get you there | Transformations (fitness, coaching, renovation) |
| **4Us** | Useful, Urgent, Unique, Ultra-specific | Headlines and buttons |
| **Features to benefits** | "X, so you can Y" | Product and service details |

## Step 3: Write

- Write in the voice from BRAND.md. Use the example line there as the tuning fork.
- Headlines: specific over clever. Say who it is for and what they get.
- Buttons say what happens next ("Book a free call", not "Submit" or "Learn more").
- Short paragraphs, plain words, "you" more than "we".
- **Never invent facts**: no made-up stats, reviews, client names, awards, or prices.
  Use `[NEEDS: real testimonial from a client]` style placeholders and list them.
- No em dashes or en dashes in site copy.
- Write SEO basics as you go: one main phrase per page (what a customer would type
  into Google), a page title under 60 characters, a meta description under 155.

## Step 4: Humanize

Run every line through the `humanizer` skill (it removes AI tells like "it's not X,
it's Y", forced lists of three, and inflated words). If humanizer is not installed,
do a manual pass for those patterns. Read headlines out loud in your head; if they
sound like an ad nobody would say, rewrite them.

## Step 5: Write brand/COPY.md

```markdown
# Copy

## Sitemap
## <Page name>
SEO title: / Meta description: / Main search phrase:
### <Section>: <job> (framework: <name>)
<the copy>
## Placeholders to fill
- [ ] <what is needed, from whom>
```

Show them the home page copy first, get feedback, then the rest. Update
`brand/PROGRESS.md`, show the Phase 6 card, recommend Phase 7 (`visual-assets`).

## Editing existing copy

When asked to improve copy on a live page: read it, name the 3 biggest problems
(vague headline, no clear action, feature lists without benefits...), rewrite with a
named framework, humanize, and show before and after side by side.
